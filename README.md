# dsh-boot-whale

A pixel whale leaps from the water as DeepSeek Harness opens. When the whale lands, the tops of the **deepseek HARNESS** letters emerge through the splash. The wordmark rises for about 2.7 seconds and settles above its reflection. It stays readable for at least 720 ms before the ready workspace fades in. If loading takes longer, ripples continue beneath the stationary letters.

The whale, lettering and water use the same dot grid. The scene fits the window and follows DSH’s light or dark background. The browser plays a silent, transparent video so frames can continue while client plugins initialize. Reduced motion displays an embedded static wordmark. The same wordmark appears if video playback fails. A DSH startup failure immediately reveals its error report.

## Install

On Desktop, use a DSH build that signals opening plugins when a visible window reloads. This lets a refresh replay the opening and return to the workspace. A build with its own startup whale can play both openings.

1. Launch DSH once to initialize the `desktop` profile, then fully quit it.
2. Install the plugin with the DSH CLI.

   ```sh
   dsh plugin --profile desktop add github:ruisenbai/dsh-boot-whale#main
   ```

3. Reopen DSH. To remove it later, fully quit DSH and run `dsh plugin --profile desktop remove dsh-boot-whale`.

The plugin injects the opening before client modules load. Desktop playback begins when the window is shown. A separate looping clip supplies the waiting ripples on slow starts. Both clips contain light and dark views of the same frame, so switching themes preserves the playback position. The opening uses the same early index injection as [dsh-video-skin](https://github.com/Something11235/dsh-video-skin). The source whale artwork derives from MIT-licensed DeepSeek Harness. See [LICENSE](LICENSE).

## Artwork development

From a source checkout, run `npm run generate:opening` to rebuild the reference atlas, frame timings, static PNG and VP9 WebM clips. Generation uses ImageMagick 7, `rsvg-convert`, and FFmpeg with libvpx. Run `npm run generate:opening -- --check` to compare the generated bytes with the committed assets.

Run `npm test` to check startup, refresh, accessible fallbacks and byte-range playback. With the artwork tools installed, the tests also decode both films and check their timing, transparency and dot pattern against the reference artwork.

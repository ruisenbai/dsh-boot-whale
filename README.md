# dsh-boot-whale

A pixel whale leaps from the water as DeepSeek Harness opens. When the whale lands, the tops of the **deepseek HARNESS** letters emerge through the splash. The wordmark rises for about 2.7 seconds and settles above its reflection. It stays readable for at least 720 ms before the ready workspace fades in. If loading takes longer, ripples continue beneath the stationary letters.

The whale, lettering and water use the same dot grid. The scene fits the window and follows DSH’s light or dark background. Reduced motion displays an embedded static pixel wordmark. If the frame atlas cannot load or draw, the static wordmark covers the remaining startup time. A DSH startup failure immediately reveals its error report.

## Install

On Desktop, use a DSH build that signals opening plugins when a visible window reloads. This lets a refresh replay the opening and return to the workspace. A build with its own startup whale can play both openings.

1. Launch DSH once to initialize the `desktop` profile, then fully quit it.
2. Install the plugin with the DSH CLI.

   ```sh
   dsh plugin --profile desktop add github:ruisenbai/dsh-boot-whale#main
   ```

3. Reopen DSH. To remove it later, fully quit DSH and run `dsh plugin --profile desktop remove dsh-boot-whale`.

The plugin inserts the opening before the client modules load and serves a fingerprinted WebP atlas. Frames store one opacity value per dot. The player applies the theme color and dot pattern as it draws. The opening uses the same early index injection as [dsh-video-skin](https://github.com/Something11235/dsh-video-skin). The source whale artwork derives from MIT-licensed DeepSeek Harness. See [LICENSE](LICENSE).

## Artwork development

From a source checkout, run `npm run generate:opening` to rebuild the atlas, frame timings and static PNG using ImageMagick 7 and `rsvg-convert`. Run `npm run generate:opening -- --check` to compare the generated bytes with the committed assets. The installed plugin uses the packaged images directly.

Run `npm test` to check startup, refresh-related window signals, accessible fallbacks and the asset route. With ImageMagick available, the artwork test also decodes the shipped frames and checks the ascent, emergence, settled lettering and waiting ripples.
